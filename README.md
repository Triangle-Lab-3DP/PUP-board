Introduction:
"PUP" is a control board specifically designed for MMU systems like EMU, where each channel requires an independent controller. Of course, you can use it for any other project you wish.

Specifications:
Main Chip: RP2040 133mhz
Dual power connectors and dual CAN interfaces for convenient daisy-chaining.
1 x Onboard TMC2226(TMC2209 in different packages) stepper driver
1 x 8-pin XH2.54 connector is provided for direct connection to the EMU Hatch Board.
2 x Neo pixel RGB interfaces, one of which is integrated into the 8-pin XH2.54 connector.
8 x I/O connectors, two of which are integrated into the 8-pin XH2.54 connector.
3 x I2C interfaces.
2 x 24V Fans Output (1A max)
1 x Heater output, 5A max
1 x NTC temperature sensor interface for temperature monitoring
1 x ADC pin for PSF Sensor
1 x SPI (AUX) interfaces
The 5V/3A output can drive larger servos.
